# 🚀 Force and Motion

A force is a **push** or a **pull**.

A push or a pull can:
- ▶️ Make an object move.
- ⏹️ Stop an object.
- ↩️ Change the way an object moves.

## ✋ Push

A push moves something away from you.

Examples:
- 🚪 Close a door
- 🛒 Push a shopping cart
- 🚗 Push a toy car
- 📦 Push a box
- 🪑 Push a chair

## 🤲 Pull

A pull brings something closer to you.

Examples:
- 🗄️ Open a drawer
- 🪢 Pull a rope
- 🧳 Pull a suitcase
- 🚪 Pull a door open
- 🚃 Pull a toy wagon

## ▶️ Start and Stop Movement

A push or a pull can make an object start moving.

Examples:
- ⚽ Kick a football to make it move.
- 🚗 Push a toy car to make it move.
- ✋ Stop a rolling ball with your hand.
- 🚲 Use brakes to stop a bicycle.

## 🏃 Fast and Slow

Some things move fast, while others move slowly.

### Fast
- 🐆 Cheetah
- ✈️ Airplane
- 🚗 Car
- 🚆 Train
- 🏃 Running

### Slow
- 🐢 Turtle
- 🐌 Snail
- 🚶 Walking

## ⚽ Rolling and Sliding

Some objects roll, and some slide.

### Objects That Roll
- ⚽ Ball
- ⚪ Marble
- 🛞 Wheel
- ⚽ Football

### Objects That Slide
- 📖 Book
- 📦 Box

Round objects usually roll.

Flat objects usually slide.

## 🌟 Remember

- ✋ A push moves an object away from you.
- 🤲 A pull brings an object closer to you.
- ▶️ A push or a pull can make an object move.
- ⏹️ We can stop moving objects.
- 🐆 Cheetahs are very fast.
- 🐢 Turtles and 🐌 snails move slowly.
- 🏃 Running is faster than walking.
- ⚽ Balls and 🛞 wheels roll.
- 📖 Books and 📦 boxes slide.
